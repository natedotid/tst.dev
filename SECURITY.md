# Security

Please report security issues privately through this repository's GitHub Security tab (Security, then Report a vulnerability), not in public issues.

## Scope

In scope:

- the code in this repository
- the tst.dev site built from it

Out of scope:

- the services the Domain Inspector talks to when you click: the Cloudflare and Google DNS-over-HTTPS resolvers and crt.sh
- Fathom Analytics

Report problems with those services to their respective vendors.
